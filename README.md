# Chinese Echoes · 皮影小剧场

Chinese shadow-theatre classroom for ages 6–12, with pinyin and Dutch / French / English support.

Live: https://chineseechoes.com/shadow-theatre/

Run `python3 -m http.server 8773`, then open http://localhost:8773/shadow-theatre/ . No installation or API key required.

Includes five story selections, timed short video excerpts, an independent introduction page, 50 original rehearsal lines, and scene images for stage mode. Full source videos are not included. For source details, subtitle scope, offline video support, and licensing, see [shadow-theatre/README.md](shadow-theatre/README.md).

Code and original scripts: MIT. Third-party videos, source excerpts, translations of those excerpts, stills, thumbnails and marks are excluded from the code license.
